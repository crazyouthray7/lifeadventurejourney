# 人生冒險誌

> 從出生到終幕，一場屬於你的人生。
> 零抽卡、零課金，純文字的人生模擬器。

## 這是什麼

一款以廣闊世界為背景的文字人生模擬器。輸入名字、選好出生城市與家境，你的人生就從一聲啼哭開始——童年、求學、就業、婚姻、老後，每個階段都是一連串的選擇，而每一次選擇，都會悄悄改變你接下來的人生。

沒有戰鬥、沒有抽卡、沒有課金。有的只是時間，和你每一次的決定。

## 特色

- **完整人生旅程**：從 0 歲到終幕，二十四個人生里程碑，涵蓋童年、青春、離巢、中年、老後的完整軌跡
- **選擇造就人生**：每個階段都有真實處境與抉擇，影響能力、財富、人脈與幸福感
- **跨城際與海外生活**：出生在北中南三個區域、國內求學工作、或出國留學與移民——留學、異鄉的第一個冬天、回鄉的班機，都是不同的人生支線
- **多元賺錢管道**：上班、投資股票基金、買房收租、虛擬貨幣、創業，甚至彩券的運氣，都能改變你的財富曲線
- **事件隨機性**：同一顆種子會長出同一棵樹，換一顆種子，就是另一種人生——每局都不同
- **情感共鳴**：以平凡生活為舞台，巷口小吃攤、家族旅行、畢業典禮、職場瓶頸……平凡人生裡的真實時刻
- **純前端，無後端**：資料保存在你的瀏覽器裡，關掉視窗也能接續上次的人生

## 怎麼玩

1. 開啟 `index.html`（或部署到任何靜態空間）
2. 輸入名字、選擇出生城市與家境，按下「開始人生」
3. 閱讀每一段人生敘事，從選項中做出你的決定
4. 一路走到終幕，回頭看你走過的這一生

> 想重新體驗不同人生？按下「重骰」換一顆種子，或直接開始新的旅程。

## 技術架構

```
index.html          入口與版面結構
engine/             遊戲引擎（數值、存檔、事件排程、角色、敘事）
themes/life/        主題資料（場景、里程碑、學校、職業、角色）
```

- 純原生 JavaScript（ES Modules），無任何框架與外部依賴（僅 Google Fonts）
- 資料透過 `localStorage` 存檔，支援「繼續上次人生」
- 響應式設計，手機與桌機都能玩
